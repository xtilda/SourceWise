THE SOURCEWISE GUIDE

A clear path to your sources.

  1. Upload a PDF with selectable text. Scanned documents require OCR, which is not currently supported.
  2. Select documents to narrow your search, or leave them unselected to search the entire library.
  3. Ask in the language of your document. Each source card includes the filename, PDF page and original excerpt.

Search matches the terms in your question against document passages. Use specific wording from your document to improve results.

This is a shared library. Anyone with the workspace password can view and delete the same documents. There are no individual user libraries.
